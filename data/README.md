# Data Folder Note

The full raw and processed project datasets remain local to the working project and are intentionally excluded from this public GitHub repository.

Why:

- the largest raw Billboard CSV is over 200 MB and is not suitable for a normal GitHub repo
- several processed analysis files are also large and duplicate local working data
- the public repo is focused on the analysis pipeline, final summaries, figures, and GitHub Pages website

What remains public:

- the R scripts that define the workflow
- the final report and phase summaries
- selected output tables and figures
- the self-contained static website under `site/`

This is a curation decision for portability and professionalism, not an attempt to hide how the project was built.
